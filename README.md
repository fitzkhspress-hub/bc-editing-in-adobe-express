# Adobe Express Broadcast Walkthrough

A self-contained KHS Cougar News classroom lesson for desktop Adobe Express. Eight steps total 8 minutes; two final knowledge checks add about 30 seconds. Hands-on editing and media processing take additional time.

## Publish with GitHub Pages

1. Create or open the GitHub repository that will host the lesson.
2. Upload the **contents** of this folder to the repository root: `index.html`, `styles.css`, `app.js`, `walkthrough.txt`, and `.nojekyll`. Do not upload the ZIP itself.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**. Choose your branch (usually `main`) and **/ (root)**, then save.
5. Wait for GitHub’s deployment to finish and open the URL shown on the Pages settings screen.

If placing this lesson in a subfolder of an existing Pages repository, retain its files together and visit that folder’s URL. All local references are relative, so project and subfolder URLs work. No build command, package installation, API key, server, or external script is required. Use a repository and Pages visibility allowed by your school.

GitHub reference: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Preview

Open `index.html` directly, or serve this folder with a local static server. The whole lesson is also in `walkthrough.txt` for printing or use without JavaScript. Browser print displays all eight steps.

## Features

- Eight navigable, timed steps with illustrative timeline diagrams.
- Optional completion checkboxes and two retryable knowledge checks.
- Downloadable plain-text edit checklist.
- Browser-local progress with a reset control; no data is submitted.
- Responsive layout, keyboard navigation, focus indicators, and reduced-motion support.
- Full text fallback when JavaScript is unavailable.

This is a guided lesson, not an embedded Adobe editor or a recorded video. Students use their own approved footage in Adobe Express. No student media is uploaded to this site. Clearing browser storage removes saved progress. When storage is blocked, the lesson still works for the current visit.

## Content

Practice outcome: an approximately 30-second, horizontal campus-news story. Adobe’s official references are linked in the lesson, checked October 26, 2026. Adobe account permissions and interface labels may vary. The guide covers in-editor captions plus a Quick action fallback. Confirm actual broadcast-system delivery requirements with the producer.
